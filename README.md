# Erudify data

Data and tooling for AI-generated Chinese flashcard sentences.

## Layout
- HSK/ : word lists (one word per line)
- corpus/ : generated sentence YAML and audio assets
- generator/ : sentence generation, coverage, and validation tools
- audio-gen/ : audio generation tool

## Nix usage
- `nix run .#coverage -- --word-list "HSK/HSK 1.txt" --sentences "corpus/HSK-1-sentences.yml"`
- `nix develop` then run `just --list` for common commands
